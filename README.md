# ASPC Cafe Homepage

Build a modern, premium, mobile-first food ordering website homepage for a college/canteen cafe called "ASPC CAFE".



IMPORTANT:

This is NOT a generic restaurant website. It is a student-friendly canteen/college cafe ordering platform. The design should feel fast, simple, youthful, affordable, clean and modern. Users should be able to immediately understand what food is available, browse categories, see popular items and add food to cart.



BRAND:

Name: ASPC CAFE

Tagline: Good Food • Good Mood



Brand personality:

- Modern

- Youthful

- Friendly

- Affordable

- Clean

- Fast

- Suitable for college students

- Not overly luxurious or formal



PRIMARY GOAL OF HOMEPAGE:

A student should be able to open the website and within a few seconds:

1. Understand that this is ASPC Cafe

2. Search for food

3. Browse food categories

4. See popular/best-selling items

5. Add an item to cart

6. Continue to the menu/cart



DESIGN STYLE:

Create a polished food-delivery-app-inspired UI, similar in usability to modern food ordering platforms, but with its own ASPC Cafe identity.



Use:

- White/off-white background

- Deep burgundy/maroon as the main brand colour

- Orange as the primary action/accent colour

- Dark charcoal for text

- Very light beige/cream backgrounds for selected sections

- Rounded cards

- Soft shadows

- Large high-quality food images

- Clean modern typography

- Generous spacing

- Subtle hover and transition animations

- Strong visual hierarchy



Do NOT make the website look like an old-fashioned restaurant website.

Do NOT display the photographed physical menu as the homepage.

The physical menu should be treated as the source of menu items and prices, while the website should present those items in modern food cards.

--------------------------------------------------

19. FINAL DESIGN DIRECTION

--------------------------------------------------



Imagine the quality level of a modern food delivery application, but make it specifically designed for ASPC Cafe.



The final result should feel:



"Wow, this is a proper modern canteen ordering platform."



It should NOT feel like:

- A basic college project

- A static restaurant website

- A PDF menu converted into a website

- An AI-generated template with random sections



Use the ASPC Cafe branding consistently throughout.



Use realistic food photography wherever possible.



Keep the overall design clean, premium, fast and student-friendly.



MOST IMPORTANT:

Build the homepage first and make it visually excellent before adding unnecessary secondary features.

The homepage must be fully responsive and functional.

All buttons and navigation elements should have sensible destinations or interactions.
